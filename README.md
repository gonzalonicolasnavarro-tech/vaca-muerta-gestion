# Vaca Muerta Gestión — Sitio Web

Sitio web institucional para **Vaca Muerta Gestión**, empresa especializada en gestión de planos, habilitaciones y permisos de construcción en la provincia de Neuquén.

## Estructura

```
/
├── index.html   # Página principal
├── style.css    # Estilos
└── README.md    # Este archivo
```

## Publicar en GitHub Pages

1. Subir estos archivos a un repositorio de GitHub
2. Ir a **Settings → Pages**
3. En *Branch*, seleccionar `main` y carpeta `/ (root)`
4. Guardar — en unos minutos la página estará disponible en `https://tuusuario.github.io/nombre-repo`
